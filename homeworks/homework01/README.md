# Homework 01: k-Nearest Neighbors and Decision Trees

Homework 01 combines the guided coding introduction from the former kNN lab with the suspect-classification decision-tree investigation. Students implement the core kNN operations, compare their predictions with scikit-learn, and use scikit-learn to train and interpret a decision tree.

[Open the student notebook in Google Colab](https://colab.research.google.com/drive/1SeIaM1sxoRnGzHkwHnJst00dI-N6LqEL)

The notebook downloads its evidence from this repository and exports the completed work as HTML for Canvas submission.
