# HW05: the unlabeled archive

- `archive_images.npz` — `X`: the 9,400 HW06 training images (byte-identical), in a fixed shuffled order (seed 2026).
- `analyst_answers.npz` — `y`: the matching labels. Students read these only through the notebook's `Analyst` class, which counts lookups. (The same labels are public in `evidence/homework06/`; the boundary is pedagogical.)
- `classes.json` — the 47 class names in ID order.

Task 04 also uses `evidence/homework04/segmented_letter_images/`.
